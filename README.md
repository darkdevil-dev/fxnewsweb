# Forex News — Landing Site

Marketing and legal landing page for the [Forex News Android app](https://play.google.com/store/apps/details?id=com.forexnews.app).

Built with React + Vite + Tailwind CSS. Deployed on Vercel at [forex.amanblaze.in](https://forex.amanblaze.in).

## Local Development

```bash
npm install
npm run dev      # dev server → http://localhost:5173
npm run build    # production build → dist/
npm run lint     # ESLint
```

## Deploy

Vercel auto-deploys on every push to `main`. Configuration is in [`vercel.json`](./vercel.json).

## Pages

| Route | Description |
|---|---|
| `/` | Home — hero, highlights, download CTA |
| `/privacy` | Privacy Policy |
| `/terms` | Terms of Service |
